# 19只A股异动监控（双模式）

交易日盘中实时监控 + 全天公告/龙虎榜消息面监控，检测到异动时推送到企业微信群机器人（企业微信失败时自动用 Server酱 兜底）。

## 两套监控

| 模式 | 监控内容 | 运行时间 | 频率 |
| ---- | ------- | ------- | ---- |
| **实时交易** | 涨跌幅、放量/缩量、主力大额、资金反转、买卖盘失衡 | 交易日 9:00-15:30 | 每5分钟 |
| **公告消息** | 重要公告、龙虎榜上榜 | 全年无休（含周末） | 每30分钟 |

> 两条线互不重复：实时交易只看盘中交易数据，公告消息只看公告/龙虎榜，避免同一信号被推两次。

## 异动信号

**实时交易类（5种，仅交易日盘中）：**
1. 涨跌幅异动 — 日内涨跌幅超过 ±5%
2. 放量/缩量 — 量比 > 2 或 < 0.5
3. 主力大额流入/流出 — 主力净流入超 ±1亿
4. 资金流向反转 — 主力当日方向与近5日趋势相反
5. 买卖盘失衡 — 买卖挂单比超过 1.5 倍

**消息面类（2种，全天）：**
6. 当天重要公告 — 标题含业绩、增减持、重组、监管等关键词，且最近40分钟内新发布（避免重复推送）
7. 当天龙虎榜上榜 — 当日登上龙虎榜（同一条当天只推一次）

## 去重机制

- 公告：只推送最近 40 分钟内新发布的，且每条公告按编号（art_code）只推一次
- 龙虎榜：同一只股票同一天的龙虎榜只推一次
- 去重状态保存在 `news_state.json`，自动清理 7 天前的记录

## 数据来源

| 数据 | 来源 |
| ---- | ---- |
| 实时行情（价格、涨跌幅、成交量、买卖五档） | 新浪财经 |
| 日K线历史（30天） | 新浪财经 |
| 实时资金流向（主力/超大单/大单/中单/小单） | 东方财富 |
| 历史资金流向（近20日） | 东方财富 |
| 最新公告（来源1） | 东方财富 |
| 最新公告（来源2） | 巨潮资讯网（证监会指定信息披露平台） |
| 龙虎榜 | 东方财富 |

> 公告数据采用双源覆盖：东方财富 + 巨潮资讯网，两个来源的公告按标题自动去重合并，确保不漏发、不重发。

## 推送方式

- **企业微信群机器人**（主，无条数限制）
- **Server酱**（备，每天5条，企业微信失败时自动兜底）

## 部署步骤

### 1. 上传代码到 GitHub 仓库

将本目录所有文件上传到 GitHub 仓库（Public，享受无限 Actions 分钟数）：

```
A股异动监控/
├── monitor.py                          # 监控脚本（双模式）
├── news_state.json                     # 去重状态（运行后自动生成）
├── .github/workflows/
│   ├── trade-monitor.yml               # 实时交易监控（每5分钟）
│   └── news-monitor.yml                # 公告消息监控（每30分钟）
├── requirements.txt
└── README.md
```

### 2. 配置推送密钥

在仓库 **Settings → Secrets and variables → Actions** 添加：

- `WECOM_WEBHOOK`：企业微信群机器人 Webhook 地址
- `SERVERCHAN_SENDKEY`：Server酱 SendKey（备选）

企业微信群机器人创建方法：企业微信 → 建内部群 → 群设置 → 群机器人 → 添加 → 复制 Webhook 地址。

### 3. 启用 GitHub Actions

打开仓库 **Actions** 标签，启用两个工作流：
- **实时交易监控**
- **公告消息监控**

可手动 **Run workflow** 测试。

## 本地运行

```bash
# 实时交易监控
python monitor.py --mode trade

# 公告消息监控
python monitor.py --mode news
```

需设置环境变量 `WECOM_WEBHOOK` 和 `SERVERCHAN_SENDKEY`。

## 注意事项

- GitHub Actions cron 可能有 1-5 分钟延迟，属正常
- 仓库保持 **Public** 才能无限运行（Private 每月 2000 分钟）
- 节假日（国庆、春节等）实时交易监控会在非交易日自动跳过；公告消息监控全年运行
- 本地自动化（WorkBuddy）和 GitHub Actions 可同时运行，两条线内容不重叠
